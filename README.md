# Deploy Checker

Внутренний инструмент DevOps-команды для проверки готовности
сервера перед деплоем. Блокирует деплой если есть критические проблемы.

## Установка
python checker.py

## Использование
# проверка локального сервера
python checker.py

# проверка удалённого сервера
python checker.py 192.168.1.100

## Что проверяется
- Доступность портов (HTTP, HTTPS, PostgreSQL, Redis)
- Свободное место на диске (WARN < 25%, FAIL < 10%)
- Запущенные процессы (PostgreSQL, Redis, Nginx)

## Статусы
- OK — всё в порядке
- WARN — есть предупреждения, деплой разрешён
- FAIL — критическая ошибка, деплой заблокирован

## Структура проекта
checker.py — основной модуль проверок
